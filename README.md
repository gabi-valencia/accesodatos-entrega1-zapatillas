# Gestión de zapatillas con ficheros en Java

Proyecto de la Unidad 1 (Ficheros) de Acceso a Datos, 2.º DAM.
IES Enrique Tierno Galván, Parla.

## ¿De qué trata?

Programa en Java para gestionar el catálogo de zapatillas de una tienda:
guardarlas en un fichero, modificar sus datos y exportarlas a XML.

## ¿Por qué este tema?

(Escríbelo tú: tu experiencia trabajando en tiendas de zapatillas
y por qué te gusta este mundo.)

## Datos de cada zapatilla

| Campo    | Tipo    |
|----------|---------|
| Código   | int     |
| Nombre   | String  |
| Marca    | String  |
| Precio   | float   |
| En stock | boolean |
| Tienda   | String  |

## Programas

- `CrearFichero_XXX.java` → crea el fichero `.dat` con las zapatillas.
- `ModificarFichero_XXX.java` → modifica una zapatilla buscándola por su código.
- `CrearFicheroXML_XXX.java` → genera un fichero XML a partir del `.dat`.
- `LeerFicheroXML_XXX.java` → muestra el contenido del XML.
- Menú principal para elegir cada opción.
